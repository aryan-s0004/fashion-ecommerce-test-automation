# Project overview

## Myntra E-Commerce Website Test Automation Using Playwright and TypeScript

**Myntra-Inspired E-Commerce Website with Automated Regression Testing**

This is a locally developed demonstration clone inspired by Myntra, not the public Myntra website. Automated tests validate this local application. React and Vite render a responsive storefront from a local JSON catalog; LocalStorage persists the cart, wishlist, and mock user profile. Modules include categories, search suggestions, product details and sizes, filtering and sorting, cart totals, wishlist, mock registration/login, and simulated checkout.

The suite uses Playwright with TypeScript and Page Object Model. The headed demo runs against installed Google Chrome and Microsoft Edge and generates video, HTML, and JSON evidence.

## Limits

This browser-only demo has no backend, real user accounts, payment, inventory, or fulfilment. Product photos use remote URLs and need network access. Demo credentials: `demo@myntra.com` / `myntra123`.
